# differs from llhttp's expected log, checked by test/conformance.cc. One line per case:
#   location<TAB>category<TAB>what differs
# split:location lines are cases where one byte at a time gives other events than one buffer.
#
# Categories (docs/perf/llhttp-evaluation.md has the table and the reasoning):
#   S-bare-lf      request smuggling: LF without CR accepted as a line end
#   S-obs-fold     request smuggling: obs-fold (a header line starting with SP/HT) accepted
#   S-value-ctl    request smuggling: control bytes accepted in a header value (and only when
#                  the buffer splits elsewhere: the verdict depends on segmentation)
#   S-te           request smuggling: Transfer-Encoding lists, chunked not final, unknown or
#                  empty codings, duplicate headers, Transfer-Encoding with Content-Length
#   S-cl           request smuggling: Content-Length with interior blanks, or empty
#   S-chunk        request smuggling: chunk size followed by a space, malformed chunk
#                  extensions, LF inside an extension
#   S-version      strictness: HTTP versions other than d.d, or not 0.9/1.0/1.1/2.0
#   R-framing      response framing (clients only): Upgrade outside 101, a body on 304
#   R-line         response status line strictness (extra space, one-digit status)
#   R-callbacks    response callbacks: on_message_begin per leading CRLF, no on_status for an
#                  empty reason
#   B-method       benign: a method or protocol outside this parser's table (REPORT, M-SEARCH,
#                  SOURCE, QUERY, PRI, ANNOUNCE, RTSP/, ICE/)
#   B-lenient      benign: the case runs llhttp with a lenient flag this parser's API lacks;
#                  this parser rejects, as llhttp does without the flag
#   B-error        benign: both reject; the callbacks before the error differ
#   B-stricter     benign: this parser rejects what llhttp accepts
#   B-close-ows    `Connection: close` followed by a tab is not recognized as close
#   B-split        benign: a slice is delivered before an error when the input is split there
